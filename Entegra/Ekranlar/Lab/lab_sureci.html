1. Ortak omurga

Tetkik kataloğu (hizmet + LIS)→ İstem (muayene / teletıp / banko / dış kurum)→ Etiket + numune alma→ Kabul (kalite, TAT başlar)→ Cihaz host query → çalış→ Sonuç + bayrak + serum indeksi→ Kural: referans · delta · panik · KK→ Teknik onay → uzman onayı (ya da oto)→ Rapor · bildirim · e-Nabız→ Saklama / imha

2. Bölüm-özel akışlar

Biyokimya / hematoloji / hormon / idrar

  • Yüksek hacim, dakika TAT; tam otomasyon (host query, oto-onay %70+). Acil testler STAT kuyruğu.
  • Hematolojide cihaz scattergram bayrakları (IG, blast şüphesi) → periferik yayma isteği (manuel diferansiyel girişi).
  • İdrar: strip + sediment (UF-5000) + mikroskopi onayı.

Mikrobiyoloji

Numune + direkt bakı (Gram)→Ekim (besiyeri seti)→İnkübasyon · planlı okumalar→Üreme → ön rapor→İdentifikasyon (MALDI-TOF / VITEK)→Antibiyogram (MIC / disk, EUCAST)→Uzman yorumu (kademeli bildirim)→Rapor · enfeksiyon kontrol bildirimi
  • TAT gün; ara raporlar (Gram, üreme, ön ID) hekime anında; kan kültürü pozitif → panik akışı.
  • Cihazlar: BACTEC alarmı (tek yön), MALDI-TOF ID dosyası, VITEK AST (HL7 BCI) → antibiyogram satırları; uzman S/I/R değiştirebilir (gerekçe).
  • Direnç mekanizması (MRSA/ESBL/CRE/VRE) → enfeksiyon kontrol komitesine bildirim, e-Nabız bildirimi zorunlu etkenler paketi.

Genetik

Vaka + ayrıntılı onam→Numune → DNA/RNA izolasyon + kalite→Kütüphane → run (NGS) / PCR→Pipeline → VCF · kalite metrikleri→Filtre → varyant değerlendirme (ACMG)→Doğrulama (Sanger) · segregasyon→Rapor (e-imza) · danışmanlık→Yeniden değerlendirme listesi
  • Vaka bazlı, TAT hafta; onam: test, tesadüfi bulgu tercihi, aile paylaşımı, veri saklama/araştırma (ayrı satırlar).
  • Ham veri (FASTQ/BAM/VCF) nesne depoda; DB'de yol + hash + run metrikleri. Pipeline sürümü raporda.
  • Varyant sözlüğü: aynı varyantın sınıfı değişince önceki vakalar yeniden değerlendirme listesine. Aile vakaları bağlı (trio, kaskad).
  • Somatik: tümör yüzdesi, VAF eşiği, tier I–IV, tedavi hedefleri.

3. Cihaz entegrasyonu — teknik

KonuKarar
KatmanLIS ara katmanı (servis): cihaz başına dinleyici (TCP sunucu/istemci, seri, klasör, API) + protokol sürücüsü (ASTM E1381 düşük seviye + E1394 kayıt / HL7 v2.x MLLP / CSV) → ortak sonuç modeli. Middleware (cobas infinity, WAM, Data Innovations) varsa tek HL7 bağlantısı.
KimlikNumune barkodu tek anahtar; cihaz PID'yi taşısa da bağlama barkodla. Barkod formatı: 10 hane + kontrol hanesi; kontrol numunesi barkodları ayrı seri (KK'ya yönlenir).
Çift yönHost query (cihaz sorar) tercih; yoksa çalışma listesi indirme. Tekrar/dilüsyon istekleri LIS'ten cihaza yeni istem.
GüvenilirlikHam mesaj önce yazılır sonra işlenir (kayıp yok); ACK zorunlu; bağlantı kopunca yeniden bağlanma + alarm (BT'ye mesaj); işlenmeyen mesajlar yeniden işlenebilir.
EşlemeCihaz test kodu → tetkik; birim/çarpan/ondalık LIS'te; cihaz referansı kullanılmaz; bayrak eşleme (H/L, > ölçüm aralığı, serum indeksi → etkilenen testler).
Genetik cihazlarRun klasörü izleme (SampleSheet ile vaka eşleme), pipeline çıktısı (VCF) içe aktarma; PCR sonuç dosyası (Ct → sonuç kuralı).
GüvenlikCihaz ağı ayrı VLAN; dinleyici yalnız beyaz listeden kabul; ham mesajlarda kimlik maskeli görünüm.

7. Ayarlar & yetkiler

  • Oto-onay açık/kapalı (bölüm ve tetkik bazlı); iki aşamalı onay zorunlu mu; acil tek aşama.
  • Panik teyit süresi ve yükseltme; delta varsayılanları; TAT uyarı eşikleri.
  • Barkod formatı/etiket şablonu; tüp birleştirme kuralı; numune saklama süresi ve imha.
  • Ham mesaj saklama süresi; cihaz alarm alıcıları.
  • Yetkiler: lab.istem · lab.numune · lab.sonuc.teknik · lab.sonuc.onay (bölüm bazlı) · lab.mikro · lab.genetik · lab.cihaz · lab.kk · lab.katalog · lab.ham_mesaj.
İlk sürüm: katalog + referans, istem/numune/barkod, 2–3 biyokimya-hematoloji cihazı (HL7/ASTM çift yön), kural motoru (referans/delta/panik), iki aşamalı onay, rapor, İKK. Sonraya: mikrobiyoloji tam akış + VITEK/MALDI, genetik (NGS pipeline entegrasyonu, varyant sözlüğü), dış lab, DKK, e-Nabız tetkik paketleri.
