Tek Ekstre — tasarım notları

  • Tek ekran, beş hesap türü: Cari (müşteri + tedarikçi), Kasa, Banka, POS, Kredi. Veri tek kaynaktan — mali_hareket (hesap türü C / K / B / P / R); bugünkü cari-ekstre ve hesap-ekstre kaynakları tek ekranın iki kipi olur. Yetki seçilen türe göre sunucuda (cari: mali_hareket, kasa / banka / POS / kredi: kasa yetkileri).
  • Ortak olan: hesap seçici (arama + son açılanlar), dönem, para birimi grupları (önce yerel, sonra USD, EUR…), Devir satırı (dönem başı bakiye), yürüyen bakiye, grup ve genel toplam (TL karşılığı), çift tık → hareketi üreten belge / kasa işlemi, Çıktı ▾ (icmallerin menüsü: Baskı Önizleme · Yazdır · PDF · Word · Excel · HTML), Liste / Detay (cari) / Aylık görünümü — Aylık: ay başı bakiye, ayın borç / alacak (giriş / çıkış) toplamı, ay sonu bakiye, hareket sayısı; aya tıklayınca o ayın hareketleri.
  • Yön ve dil türe göre: Cari'de Borç / Alacak ve bakiye B / A; Kasa, Banka, POS, Kredi'de Giriş / Çıkış. Sütun adları ve toplanan sütunlar seçili türden gelir — aynı ızgara.
  • Türe özgü: Cari — vade sütunu, vadesi geçen kutusu, mutabakat mektubu, devir / açılış, Detay görünümünde belge kalemleri. Kasa — cari / karşı hesap sütunu, gün sonu sayımı ve fark. Banka — karşı hesap, eşleşme sütunu (banka hareketiyle — API / ekstre dosyası), bloke. POS — komisyon, valör, bankaya geçen. Kredi — taksit no, ana para / faiz ayrımı, ödeme planı.
  • Giriş yolları: Müşteri / Tedarikçi / Kasa / Banka / POS / Kredi listelerinin "📄 Ekstre" düğmesi ve kartlardaki "📄 Ekstre" bu ekranı ilgili hesapla yeni sekmede açar; menüde tek madde Finans › Ekstre. Bugünkü Kasa › Cari Ekstre ve hesap ekstresi rotaları buraya yönlenir.
